# Examples

Two decks built with this skill and used in real talks. They are included as they were presented, except that media that cannot be redistributed under this repository's license has been removed. Open the `index.html` files locally or on GitHub Pages.

## category-theory-night-2026 — 圏論は(どう)役に立つのか

- Talk: "Is category theory (and how) useful?", 圏論NIGHT at the academic bar Q, Tokyo, 2026-09-05 (Japanese). Speaker: Ryuya Hora; discussion with Kory.
- Source: the speaker's Beamer deck, converted to HTML the night before the talk. Text is copied from the Beamer source; the puzzles (15-puzzle, king's walk, infection board, Rubik's cube) are playable.
- Colors: orange = operation, green = (invariant) quantity, navy = emphasis/links, red = impossible.
- Photos: the speaker's own (an exhibition, conference rooms) and book covers shown as bibliographic references with links to the publishers.
- Everything in this folder: MIT, © Ryuya Hora.

## math-cafe-2026 — 文字列から現代数学へ

- Talk: "From strings to modern mathematics", 数学カフェ advanced lecture for high-school students, Taito, Tokyo, 2026-09-12 (Japanese, 3 × 30 min). Speaker: Ryuya Hora.
- Built from the speaker's approved outline and notes; 38 slides; top-dot navigation grouped by chapter; interactive counting of strings/polynomials (n = 1…12), rotations, Frobenius, coverings, a synchronized three-column model.
- Colors: orange = discrete, green = continuous (introduced from chapter 2).
